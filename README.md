Микросервисы для мобильного приложения сети кофеен. Управление заказами, бонусами, меню и авторизацией.

---

##  О проекте

Coffee Club помогает клиентам:
- Заказывать кофе с настройкой (объём, сироп)
- Копить и тратить бонусы
- Оплачивать Apple/Google Pay
- Повторять любимые заказы в 2 клика

**Цели:**
- Упростить заказ
- Повысить средний чек (кастомизация)
- Увеличить повторные покупки (бонусы)
